# Third-party provenance

Seam references these binaries from the supplied CodeWalker dev46 distribution:

- `CodeWalker.Core.dll` — CodeWalker by dexyfex, assembly version 1.0.0.0.
- `SharpDX.dll` and `SharpDX.Mathematics.dll` — SharpDX 4.2.0 dependencies used by that distribution.
- `Notice.txt` — the distribution's original notices, retained as `lib/Notice.txt` and embedded in the executable. Read them in the app through Guide → Third-party notices.

Public source was inspected at [dexyfex/CodeWalker](https://github.com/dexyfex/CodeWalker), commit `485d56bec00262ed7fa472261cce7bbc6202b96e`. Its `Readme_Src.txt` states: “This source code is released for educational purposes only.” The third-party files are not relicensed by this project. The source checkout is not a build dependency and is not included here.

Static inspection used REA 6.7.0, which is not a runtime dependency. The clothing editor and pack builder are independent original code; no reference application's proprietary modules are included.

Demo models, textures, placements and collision bounds are generated by `app/DemoFactory.cs`. No game models, textures, encryption keys, personal map resources or generated pack exports are distributed.
